An entry for the make.fun bounty [Alien Field Notes: The Two Day Earth Review](https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000).

The program in `main.py` writes one line to `/output/entry.txt`: a review of
planet Earth left by an alien tourist, noting that the species built a device
that can summon any fact instantly and mostly uses it to argue with strangers
and photograph soup. The line is assembled from fragments, checked against
the 200-character gate, written as UTF-8 with no trailing newline, and read
back for a byte-for-byte comparison before the program exits.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
